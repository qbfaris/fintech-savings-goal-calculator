# FinTech Project 3: Savings Goal Calculator

This is a simple Python program that estimates how long it will take to reach a savings goal.

## How to run it

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run `python savings_goal_calculator.py`.
4. Enter your goal, your current savings, and how much you plan to save each month.

## Example

- Savings goal: $1000
- Current savings: $200
- Monthly savings: $150
- Result: 6 months, with $1100 saved

The calculator assumes you save the same amount each month. It does not include interest.
